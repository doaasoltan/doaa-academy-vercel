# أكاديمية دعاء سلطان — نسخة مستقلة عن Manus

هذه النسخة لا تستخدم Manus OAuth أو Manus Storage. تسجيل الدخول والتخزين يعملان محليًا على جهازك.

## المتطلبات
- Windows 10/11
- Node.js 20 LTS أو أحدث
- pnpm
- MySQL 8

## التشغيل
1. فكّي الضغط في مجلد مثل `C:\DoaaAcademy`.
2. افتحي PowerShell داخل المجلد.
3. نفذي:
   `pnpm install`
4. أنشئي قاعدة MySQL باسم `doaa_academy`.
5. أنشئي ملف `.env` بالقيم المطلوبة، وأهمها:
   `DATABASE_URL="mysql://root:كلمة_المرور@127.0.0.1:3306/doaa_academy"`
6. نفذي:
   `pnpm db:push`
7. شغّلي:
   `pnpm dev`
8. افتحي العنوان الذي يظهر في PowerShell، غالبًا:
   `http://localhost:3000`

## الدخول المحلي
- من الصفحة الرئيسية: زر تسجيل الدخول يدخل بحساب طالبة محلي.
- عند فتح `/admin` ثم تسجيل الدخول، يتم الدخول بحساب الإدارة المحلي.
- لا توجد صفحة Manus أو OAuth في هذه النسخة.

## ملفات PDF والفيديو
الملفات تُحفظ داخل مجلد `uploads` في المشروع، وتظهر من خلال `/uploads/...`.
حد PDF: 50MB.
حد الفيديو: 100MB.

> هذه النسخة مناسبة للتشغيل المحلي والاختبار. إذا أردتِ نشرها على الإنترنت، يجب إضافة نظام دخول حقيقي وآمن بدل تسجيل الدخول المحلي التلقائي.
